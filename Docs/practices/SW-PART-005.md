## Наша интерпретация

Наш критерий простоты — возможность объяснить назначение каждого объекта и определяющего параметра. Равенство или симметрию, требуемые замыслом, выражаем зависимостью, а не случайно равными независимыми числами. Числовой лимит объектов и обязательное разбиение каждого эскиза не вводятся.

## Применимость

- Новый эскиз с повторяющимися или симметричными элементами.
- Согласованная переработка сложного эскиза, вызывающего ошибки редактирования.

## Исключения

- Элементы внешне одинаковы, но по назначению должны изменяться независимо.
- Единый профиль обязателен для выбранного bounded-сценария.
- Оставленная степень свободы явно предусмотрена методикой; автоматическое полное определение может подменить замысел.

## Входные параметры и базы

- Список объектов и их назначение
- Независимые размеры
- Геометрические отношения
- Ожидаемые изменения
- Разрешённые степени свободы

## Сохраняемые условия

- Каждая обязательная зависимость имеет проверяемое представление в модели.
- Нет неразрешённого конфликта связей и размеров.
- При изменении общего параметра сохраняются требуемые равенства или симметрия.

## Предлагаемый метод

- Создать только геометрию, необходимую для выбранного профиля.
- Добавить отношения по замыслу, затем определяющие размеры; при необходимости изменить порядок.
- Проверить оставшиеся степени свободы и конфликты.
- Изменить один общий параметр, прочитать зависимые значения и результат перестроения.

## Необходимые возможности

- Создание и чтение выбранных отношений эскиза
- Чтение статуса определения и конфликтов
- Чтение независимых и зависимых размеров
- Изменение общего параметра
- Перестроение и проверка профиля

## Наши проверочные сценарии

- `SW-PART-005-N1` — native, `not_run`.
  Процедура: После отдельной поддержки equal-связи создать собственную пару кругов с требованием общего диаметра, изменить один определяющий диаметр и прочитать связь и оба значения.
  Ожидается: Диаметры изменяются совместно средствами модели; профиль не имеет конфликта. Исходно равные числа без связи не проходят эту проверку.
- `SW-PART-005-S1` — skill, `passed`.
  Процедура: Дать два одинаковых по исходному диаметру отверстия, которые пользователь требует изменять независимо.
  Ожидается: Навык не добавляет равенство только из-за исходного числового совпадения.

## Ограничения

- Прочитанные рекомендации не устанавливают обязательное число эскизов или объектов.
