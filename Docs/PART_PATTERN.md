# Линейный массив сквозных отверстий

Кандидат dev57, native-приёмка пока не выполнена. Последний принятый блок —
редактор отверстия dev56; его результаты не переносятся на новый wheel.
Все три стадии PLAN.md остаются открыты. Импорт и экспорт отложены.

## Инженерный сценарий

Новая деталь → прямоугольная база → полностью определённое сквозное отверстие →
один native SOLIDWORKS LPattern вдоль положительного локального X или Y базы.
Предварительный профиль: одна активная записываемая деталь, одна конфигурация,
одна база с одним собственным круглым вырезом. Число экземпляров 2–64 включает
исходное отверстие; постоянный шаг в мм. Между отверстиями и до каждого края
должно оставаться >=0,001 мм материала. Новый элемент дерева по-русски:
«Линейный массив отверстий» по умолчанию.

Двухнаправленные и круговые массивы, массивы тел/граней, пропуски экземпляров,
переменный шаг, произвольные импортированные детали, редактирование после
создания массива и типовые стандартные детали библиотеки не входят в этот scope.

## MCP-контракт

| Инструмент | Результат |
| --- | --- |
| `part_prepare_linear_hole_pattern` | Проверяет исходную модель и ввод, возвращает ревизию и ожидаемую полную форму; CAD не меняет |
| `part_create_linear_hole_pattern` | Создаёт один собственный native массив по точной подготовленной ревизии |

В обе операции передаются явные `document_id`, `configuration`, `base_object_id`
эскиза базы, `object_id` окружности, `seed_object_id` её точного выреза из
`feature_list`, `direction_edge_id` из `edge_list` текущего тела, `count`,
`spacing_mm` и русское `feature_name`. Для записи также обязательны
`expected_revision` и `request_id`. Область ревизии:
`single_base_linear_through_hole_pattern_v1`.

Направление не выбирается по имени или текущему выделению. Persistent reference
ребра подтверждается в исходном теле. Реальные конечные вершины должны образовать
полное внешнее ребро кубоида вдоль X/Y; знак направления передаётся в native API.
Ребро вдоль толщины, диагональ, частичное или внутреннее ребро отвергаются.
Ревизия связывает документы, конфигурацию, native ссылки, исходные размеры и
ограничения, полный BREP, состояние controls, количество, шаг и имя.

## Проверка и восстановление

Durable checkpoint предшествует изменениям CAD/UI. Созданный IFeature удерживается
до переименования и следующих вызовов, без поиска по разнице имён. Native
`ILinearPatternFeatureData` подтверждает seed, ребро направления, число и шаг,
отсутствие пропусков, второго направления и GeometryPattern/VarySketch.
`AccessSelections` используется только после checkpoint под guard, освобождается
до двух независимых чтений окончательного тела; промежуточный rollback не является
результатом массива. Повторное чтение scalar-параметров не открывает rollback.

Подтверждаются исходные эскизы, отношения и все старые размеры, ровно один новый
LPattern и только принадлежащие ему новые размеры. Полный BREP-читатель проверяет
все стенки, замкнутые циклы, партнёров coedge и непересекающиеся отверстия.
Сопоставление формы проверяет координаты/радиусы всех отверстий и их связь с
контуром обеих торцевых граней; совпадения массы и количества граней недостаточно.
Независимые native объём и площадь также должны совпасть с ожидаемыми.

Известный подтверждённый сбой удаляет только собственный массив через
`DeleteSelection2(0)`: исходный вырез, его эскиз и база сохраняются. После удаления
проверяется полное исходное состояние. Чужой или нечитабельный эффект не разрешает
удаление, даёт unknown и удержание приложения. Повтор `request_id` не повторяет
CAD-запись; тайм-аут ожидания не означает отмену COM.

## Основания для native API

Сигнатура `FeatureLinearPattern4`, свойства и методы `ILinearPatternFeatureData`
сверены с зарегистрированной type library SOLIDWORKS 2023. Официальные источники:
[FeatureLinearPattern4](https://help.solidworks.com/2024/english/api/sldworksapi/SolidWorks.Interop.sldworks~SolidWorks.Interop.sldworks.IFeatureManager~FeatureLinearPattern4.html),
[ILinearPatternFeatureData](https://help.solidworks.com/2023/english/api/sldworksapi/SolidWorks.Interop.sldworks~SolidWorks.Interop.sldworks.ILinearPatternFeatureData.html?id=2.2.1.193).
Реальная CAD-приёмка публикуется только после выполнения installed-wheel сценариев.
