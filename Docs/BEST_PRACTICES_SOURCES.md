## SRC-AS-01 Building Stable SOLIDWORKS Assemblies

[Первоисточник](https://blogs.solidworks.com/products/solidworks/building-stable-solidworks-assemblies/)

Издатель: Dassault Systèmes SOLIDWORKS. Продукт: SOLIDWORKS desktop.
Редакция: Официальная статья; версия продукта не указана. Дата публикации: не установлена.
Дата доступа: 2026-10-11. Прочитано: Start with Motion, Not Geometry; Fully Defined Is Not Always the Goal; Understanding Rigid and Flexible Subassemblies; Keep In-Context References Under Control.
Состояние доступа: `read`.

Извлечённые положения:

- Сопряжения должны сохранять движение, требуемое назначением компонента; полное ограничение подходит неподвижным компонентам.
- Повторное ограничение уже заданного поведения может сделать схему избыточной.
- Внешняя зависимость должна идти от владельца размера к зависимым деталям; обратная ссылка образует цикл.
- Гибкая подсборка открывает внутреннее движение родительской сборке; для нескольких фиксированных положений возможны конфигурации.

Границы источника:

- Статья иллюстрирует методику на шахматных часах; это не спецификация CAD API.
- Дата публикации и версия SolidWorks не подтверждены в прочитанном предметном тексте.
- Прочитана через web open; изображения и чужие CAD-файлы в реестр не включены.

## SRC-AS-02 Best Practices for Mates

[Первоисточник](https://help.solidworks.com/2023/english/SolidWorks/sldworks/c_Best_Practices_for_Mates_SWassy.htm)

Издатель: Dassault Systèmes SOLIDWORKS. Продукт: SOLIDWORKS desktop.
Редакция: SOLIDWORKS Design Help 2023 SP05 (footer). Дата публикации: не установлена.
Дата доступа: 2026-10-11. Прочитано: Best Practices for Mates: пункты о фиксированных базах, цепочках, циклах, избыточных сопряжениях и допустимом движении.
Состояние доступа: `read`.

Извлечённые положения:

- По возможности компоненты сопрягают с одной или двумя фиксированными базами; длинные цепочки усложняют решение.
- Циклы и избыточные сопряжения затрудняют сопровождение; совпадающие ограничения расстояния могут переопределить модель.
- Остаточное движение проверяют; полное определение рекомендуют с исключением для необходимого движения.
- При сочетании сопряжений и контекстных элементов следует избегать круговых ссылок.

Границы источника:

- Полный предметный текст прочитан через скрытую browser-страницу; web open возвращал только JS-оболочку.
- Редакция SP05 не доказывает поведение API в целевом SolidWorks 2023 SP2.1.
- Рекомендации о перепостроении сопряжений не разрешают автоматически удалять пользовательские сопряжения или исправлять неизвестный исход.

## SRC-AS-03 Flexible Subassemblies

[Первоисточник](https://help.solidworks.com/2023/english/SolidWorks/sldworks/c_Flexible_Sub-Assemblies.htm)

Издатель: Dassault Systèmes SOLIDWORKS. Продукт: SOLIDWORKS desktop.
Редакция: SOLIDWORKS Design Help 2023 SP05 (footer). Дата публикации: не установлена.
Дата доступа: 2026-10-11. Прочитано: Flexible Subassemblies: Mates; Multiple Instances; Making a Subassembly Flexible; Toggling Between Flexible and Rigid States.
Состояние доступа: `read`.

Извлечённые положения:

- В гибкой подсборке внутренние сопряжения решаются вместе с родительскими, а движение сохраняет ограничения.
- Разные экземпляры подсборки могут иметь разные состояния гибкости и положения.
- Гибкость недоступна для lightweight-подсборок.
- Описанное переключение гибкости изменяет только активную конфигурацию.

Границы источника:

- Полный предметный текст прочитан через скрытую browser-страницу; web open возвращал только JS-оболочку.
- Редакция SP05 не подтверждает COM-совместимость с целевым SolidWorks 2023 SP2.1.
- Гибкая подсборка отличается от Make Part Flexible; перенос правил на гибкую деталь не заявлен.
