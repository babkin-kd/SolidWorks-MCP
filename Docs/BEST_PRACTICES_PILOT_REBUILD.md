## GetEquationMgr

[GetEquationMgr Method (IModelDoc2), actual URL](https://help.solidworks.com/2023/english/api/sldworksapi/SolidWorks.Interop.sldworks~SolidWorks.Interop.sldworks.IModelDoc2~GetEquationMgr.html).

| Поле Help 2023 | Прочитанное содержание |
| --- | --- |
| Description | Получить менеджер уравнений |
| Syntax | `EquationMgr GetEquationMgr()`; Visual Basic возвращает `EquationMgr` |
| Parameters | Отдельный раздел отсутствует; сигнатура без аргументов |
| Return Value | Менеджер уравнений, не Boolean |
| Remarks | Менеджер позволяет работать с существующими уравнениями и изменять конкретное уравнение. Объект связан с конфигурацией, активной в момент получения; после смены активной конфигурации удерживаемую ссылку следует освободить и получить заново |
| Availability | SOLIDWORKS 2001Plus FCS, Revision Number 10.0 |
| Version/footer/access | 2023 / SP05, footer выше; 2026-10-11; read через UI |

Наш проектный вывод: executor должен получать менеджер внутри явного
document/configuration-контекста. Нельзя переносить удерживаемую ссылку через
смену конфигурации. Получение менеджера не подтверждает, что требуемое уравнение
существует, активно, вычислено или связывает нужные native-размеры.

## EditRebuild3

[EditRebuild3 Method (IModelDoc2), actual URL](https://help.solidworks.com/2023/english/api/sldworksapi/SolidWorks.Interop.sldworks~SolidWorks.Interop.sldworks.IModelDoc2~EditRebuild3.html).

| Поле Help 2023 | Прочитанное содержание |
| --- | --- |
| Description | Перестроить только элементы, нуждающиеся в перестроении, в активной конфигурации модели |
| Syntax | `System.bool EditRebuild3()` |
| Parameters | Отдельный раздел отсутствует; сигнатура без аргументов |
| Return Value | Boolean: true при выполнении указанного перестроения нуждающихся элементов активной конфигурации, иначе false |
| Remarks | Метод работает только в контексте активного документа |

Наш проектный вывод: вызов имеет область dirty-only в активной конфигурации.
Он не обещает принудительно вычислить все элементы или остальные конфигурации.
Возвращённый true — подтверждение результата API в этой области, не доказательство
нужного конструкторского замысла, графа зависимостей или формы.

## ForceRebuild3

[ForceRebuild3 Method (IModelDoc2), actual URL](https://help.solidworks.com/2023/english/api/sldworksapi/SolidWorks.Interop.sldworks~SolidWorks.Interop.sldworks.IModelDoc2~ForceRebuild3.html).

| Поле Help 2023 | Прочитанное содержание |
| --- | --- |
| Description | Принудительно перестроить все элементы активной конфигурации модели |
| Syntax | `System.bool ForceRebuild3(System.bool TopOnly)` |
| Parameters | `TopOnly=true`: только верхний уровень сборки; `false`: верхний уровень и все подсборки |
| Return Value | Boolean: true при перестроении всех элементов активной конфигурации на указанном уровне сборки, иначе false |
| Remarks | Отдельный раздел отсутствует на прочитанной странице |
| Availability | SOLIDWORKS 2001Plus FCS, Revision Number 10.0 |
| Version/footer/access | 2023 / SP05, footer выше; 2026-10-11; read через UI |

Наш проектный вывод: force относится к элементам активной конфигурации.
`TopOnly=false` расширяет уровень сборочного перестроения, но не означает
перестроение всех конфигураций. Эта страница не уточняет отдельное поведение
параметра для детали; не следует приписывать ему недокументированные значения.
Принудительное перестроение также не сертифицирует граф или геометрию пилота.

## Сопоставление с текущим адаптером

Проверен текст [cad_dimensions.py](../src/solidworks_mcp/cad_dimensions.py),
без запуска адаптера и без изменений:

- `dimension_context` получает менеджер через `model.GetEquationMgr()` и
  `binding.wrap(..., IEquationMgr)`, отклоняя недоступный менеджер. Детали
  используемых методов менеджера относятся к отдельному исследованию.
- Функция `rebuild_dimension_document` перед вызовом получает текущий active document и
  сравнивает canonical identity с явной моделью; несовпадение даёт
  `document_not_active`.
- Она вызывает `model.ForceRebuild3(False)` через существующий `timed_call`.
  Результат принят только при `rebuilt is True` и `pending_rebuild(model) is False`.
  Проверка точного Boolean — факт текущей реализации. Реальное представление
  возвращаемого COM-значения в pywin32 этим чтением справки не проверялось.
- Комментарий адаптера объясняет выбор force наблюдением, что на SW2023
  `EditRebuild3` после `SetSystemValue3` может вернуть true при неизменном теле и
  установленном pending-флаге. Здесь зафиксировано содержание комментария;
  это не новое воспроизведение или native-доказательство такого поведения.

Документированные области вызовов согласуются с различием dirty-only/force.
Проверка identity в адаптере также сохраняет явный контекст. Однако этот helper
не читает граф зависимости пары отверстий и не сопоставляет полную целевую форму.
API ACK плюс отсутствие pending-флага — один шаг приёмки изменения.

## Требования к будущему пилоту

Ниже — требования нашего проекта, не дополнительные обещания этих API-страниц:

1. До записи зафиксировать document/configuration, ревизию поддержанной полной
   области, native-цели параметров и ID/версию практики. Защитить жизненный цикл
   менеджера уравнений; смена конфигурации не может оставаться незамеченной.
2. После изменения W и вычисления зависимости выполнить выбранное guarded-
   перестроение; проверить точный исход и отсутствие pending-состояния.
   Возврат false или исключение требует установить фактический исход задания.
3. Прочитать фактическую зависимость `x1=e`, `x2=W-e`, роли параметров и состояние
   решателя. Проверить e, Y, D и T; не заменять связь совпадением чисел.
4. Сопоставить полную поддержанную BREP пластины с двумя отверстиями и независимые
   геометрические факты для W=100→140 мм. Подтвердить центры 20/80→20/120 мм
   без клиентского пересчёта координат.
5. Сохранить свою модель, повторно открыть, заново получить контекст/ссылки и
   проверить W=120 мм с центрами 20/100 мм. Положительный ACK не доказывает
   сохранение зависимости после открытия.

Все пункты выше пока **not_run** для этого пилота. Чтение Help 2023 SP05 не
проверяет type library/pywin32 bindings целевого SP2.1 и не является installed-
wheel, CAD или публичной MCP-приёмкой. Реализация уравнений, полного scope
изменения основания после отверстий и lifecycle-предпосылок остаётся задачей
отдельного инженерного блока после разрешённого перехода стадии.
