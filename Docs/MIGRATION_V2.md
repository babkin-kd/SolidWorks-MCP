# Миграция legacy-инструментов в API v2

В dev23 добавлен внутренний структурный расчёт `feature.deletion_structure`: выбранные persistent targets и явные children/absorbed flags, причины включения, оставшиеся связи, циклы, отдельная ревизия и blockers. **53 связанных pure-теста прошли**. Это частная основа полного preview из 1.4; полного воздействия и исполнения удаления ещё нет, операция не опубликована и не прошла native-приёмку. Уравнения, другие конфигурации, аннотации/чертежи, внешние ссылки и native-результат/откат остаются непроверенными областями. Публичный каталог содержит прежние 18 инструментов; установленный wheel остаётся dev21.

Последний исходный кандидат — dev23: внутренний граф `feature.dependencies` связывает два полных снимка native-зависимостей с persistent references и отдельной ревизией, проверяет canonical identity и закрывает чтение проверкой контекста/уведомлений. Это подготовка полного предварительного просмотра удаления в 1.4, а не доступность удаления: `deletion_impact_complete=false`, `deletion_authorized=false`; граф не опубликован и не проверен в native. Публичный каталог остаётся из 18 инструментов. Последний общий набор: **1814 pure passed, 321 native deselected**.

Установленный wheel остаётся dev21 (`f3f3001`), с принятой внутренней размерной и внутренней/публичной экспортной проверкой. После подтверждения пользователя о закрытии контрольных деталей и сохранении текущей точности STL принято новое исходное состояние для свежей публичной размерной проверки с exact preference diagnostics. Свежая попытка не принята: запись succeeded/committed, затем изменилась только `stl_deviation` (0,10488088481701517 → 0,11916375287812985 мм), при неизменных quality=3 (Custom) и остальных 18 проверяемых настройках. Точные снимки сохранены; причина не доказана. Две новые контрольные детали оставлены, дальнейшие CAD-вызовы остановлены до согласования состояния. Прежние журналы и committed записи не изменены. Рабочая v1 сохранена. Стадии 1–3 остаются в полном согласованном объёме; push/CI и дополнительные агенты не запускались. Следующие абзацы — история прежних сборок/проверок.

Текущая native-приёмка dev21 (`f3f3001`): публичные `export_prepare`/`export_part` приняты через настоящий stdio для STL мм/м/дюймы, STEP, Parasolid в поддерживаемом planar scope; исходная сессия восстановлена. Внутренние размеры приняты, публичная размерная проверка остановлена после committed записи на независимом сравнении общих настроек. Её нельзя считать принятой: причина неизвестна, две собственные детали и журнал сохранены до согласования нового исходного состояния. Скрипт дополняется пассивными snapshot diagnostics и отчётом отказа; **1745 pure passed, 321 native deselected**. Новый пакетный каталог содержит 18 инструментов, регрессия переименования на нём ещё впереди. Статусы «Изменено / частично» не означают завершение 1.4.

Локальный набор регистрации dev21: **1737 passed, 321 native deselected**. Через реальный MCP stdio подтверждены каталог из 18 инструментов, outputSchema, guide и отказ экспорта без операторской настройки до CAD. Установленный wheel/native-приёмка проверяются отдельно.

Текущий исходный кандидат — dev21: зарегистрированы пять подготовленных инструментов размеров/экспорта; публичный каталог содержит 18 инструментов. Внутренние native-проверки размеров и STL мм/м/дюймы, STEP, Parasolid приняты на dev19. Проверки нового установленного пакета и публичных MCP-команд остаются отдельными gates; их результат не подменяется прежней приёмкой. Внутренний сборщик зависимостей dev20 ещё не объявляется инструментом удаления. Рабочая v1 сохранена отдельно.

## Новые инструменты без legacy-аналога

`job_get`, `job_list`, `job_cancel`: устойчивое состояние, независимый опрос, отмена очереди. `geometry_get`: восстановление зарегистрированного тела/грани/ребра, проверка native-ссылки и присутствия в активной геометрии. `document_get`: явное чтение заданного документа/конфигурации.

## Непокрытая область

Ревизии изменений, блокировка неопределённого документа, доменный откат, импорт/экспорт и запись существующих параметров ещё требуют native-приёмки стадии 1. Полнота таблицы — это полнота инвентаризации, а не готовность функций. Большие сборки, PDM Professional, сварные конструкции, чертежи, кинематика, сетки/печать и Simulation остаются в полном плане.

На том же чистом установленном dev19 (`e32cfb3`) принята внутренняя операция размеров: физически проверено 7 → 9 мм и scoped restoration 11 → 9 мм после искусственной Python-ошибки за реальным setter. Подтверждены устойчивая ссылка после rebuild, отсутствие повторной записи, stale revision отказ, durable UI guard и восстановление исходной сессии. Выполнено 3 native записи и 2 rebuild; native COM-ошибка не инъецировалась. Публичная MCP-приёмка размеров и приёмка исходного dev20 не выполнены.
